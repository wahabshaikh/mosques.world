# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/wahabshaikh/mosques.world/security/advisories/new),
or by email to salam@mosques.world. Do not open a public issue.

Include the affected URL or file, steps to reproduce, and the impact you expect. We aim to acknowledge reports
within three days and to fix confirmed issues before disclosing them.

Only the live site (`mosques.world`) and the code in this repository are in scope. Preview deployments on
`workers.dev` run against test data and deliberately expose test hooks; report them only if they reach production
data or secrets.
